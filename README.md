# 🌙 웹 마피아 게임

링크만 있으면 폰으로 바로 하는 멀티플레이 마피아 게임. 서버도, 가입도, 돈도 필요 없습니다.

## 하는 법
1. 한 명이 사이트에 들어가서 닉네임 쓰고 **방 만들기** → 이 사람이 방장
2. 방장이 **🔗 초대** 눌러서 링크를 단톡방에 보내기 (방 코드 4자리를 불러줘도 됨)
3. 4명 이상 모이면 방장이 **게임 시작**

- 직업: 마피아(4~5명이면 1명, 6~8명은 2명, 9명 이상은 3명), 의사, 경찰, 시민
- 흐름: 밤(40초) → 낮 토론(90초) → 투표(30초) → 다시 밤 …
- 마피아끼리만 보이는 비밀 채팅이 있고, 경찰 조사 결과는 본인한테만 보임
- 방장 화면의 **⏭ 넘기기**로 시간 안 기다리고 넘길 수 있음

## 주의
- **방장 폰이 서버 역할**을 합니다. 게임 중에 방장이 화면을 끄거나 다른 앱에 오래 가 있으면 연결이 끊길 수 있어요. 방장은 충전기 꽂고 화면 켜두는 게 좋아요.
- 연결이 끊겨도 새로고침하거나 다시 들어오면 이어서 할 수 있어요 (방장도 마찬가지).
- 일부 통신사·와이파이 조합에서는 연결이 안 될 수 있어요. 그럴 땐 와이파이↔데이터를 바꿔보세요.
- 방장 폰이 판정을 하니까, 방장은 마음먹으면 개발자도구로 직업을 볼 수 있어요. 믿을 만한 사람이 방장 하세요.

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` / `style.css` | 화면 |
| `app.js` | 게임 로직 전부 (방장 판정 + 참가자 화면) |

PeerJS(WebRTC)로 참가자 폰이 방장 폰에 직접 연결됩니다. 방장은 전체 게임 상태를 들고 있다가, 각 사람에게 **그 사람이 봐도 되는 정보만** 골라서 보냅니다. 그래서 다른 참가자는 남의 직업이나 마피아 채팅을 볼 수 없어요.

설정은 `app.js` 맨 위에서 바꿀 수 있어요.

```js
const DURATION = { night: 40, day: 90, vote: 30 }; // 각 단계 시간(초)
```
